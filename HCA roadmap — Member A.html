Proposed targets: collect a four-week local baseline; evaluate each pilot for 12 weeks. Require at least 80% active adoption per tool. Time savings never override safety or quality findings.

Phase explanations and decision handoff

Crawl rationale

Crawl prepares selected sites for integrated production. I1 provides approved data access, I2 validates record interfaces and workflows, and I3 establishes oversight. These workstreams can begin in parallel; I2 can use test records before the shared platform is complete. Without I2, I5 lacks tested note write-back and I6 lacks validated access to current patient records, so both fail our proposed production gate. Timpani instead needs workforce feeds and scheduling rules. The nine-month foundation covers local readiness, while the broader Expanse migration continues separately. Walk starts only after the relevant checks pass.

Walk rationale

Walk tests whether the tools help real staff in a controlled setting. Timpani, clinical documentation and nurse handoff use the foundation differently, so each needs its own baseline, limited deployment and measured result. A favorable demonstration is not enough. The pilots must show less administrative work without weaker clinical quality or staffing compliance, and users must actually adopt the tools. These checks justify later investment and reveal training or workflow changes while the exposure is still small. Only a successful pilot moves into its corresponding Run rollout.

Run rationale

Run expands proven deployments rather than introducing untested use cases. Each rollout inherits its pilot’s evidence, but a new hospital still needs local data, training and safety checks. Enterprise standards create consistency, while an exception process recognizes that hospitals and units differ. Scaling therefore requires organizational changes: local champions, clear ownership, continuing audits and support for staff. We release investment in waves and pause when quality, adoption or benefit targets are missed. This prevents a large installation count from being mistaken for a successful transformation.
